# [Opra] Motherlode Mine

Mines paydirt in the Motherlode Mine. Imported from [Microbot Hub](https://github.com/chsami/Microbot-Hub/tree/main/src/main/java/net/runelite/client/plugins/microbot/motherloadmine) at version 1.9.7 so it can be rebuilt here. The hub copy is the baseline, not the version to keep.

## Setup

1. Start near the bank chest in the Motherlode Mine.
2. Install it with `installer\OpraMicroHub-Setup.bat`, restart the client, then enable **[Opra] Motherlode Mine**.
3. Disable the hub Motherlode Mine plugin so both are not running.

## Config

The config group is still `micro-motherloadmine`.

- **Enable Inventory Setup** / **Inventory Setup**: optional gear from the inventory setups plugin.
- **Use Deposit All**: deposit box uses deposit-all. Lock the slots you want to keep.
- **Anti Crash**: avoid other players on the lower level.
- **Drop Gems**: drop gems while mining.
- **Use Mine Upstairs** / **Use Upstairs Hopper**: upper level and the upstairs hopper.
- **Mining Area**: which vein area to use. Default is any.
